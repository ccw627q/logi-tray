# logi-tray

一个常驻 Windows 托盘栏的罗技（Logitech）设备电量显示工具。直接和接收器/设备通信，不依赖 Logitech Options / G HUB。

## 功能

- **托盘图标显示电量**：图标即当前设备的电量，支持 3 种样式（双击托盘图标循环切换，样式会记住）
- **悬停 tooltip**：首行是当前设备（带 `●` 标记），其后最多再列 2 个设备，超出以 `…` 结尾
- **右键菜单**：
  - 设备管理标题（`N 个设备 · M 个在线`）
  - 设备列表，`●` 标记当前设备，点击任意一行即可切换当前设备
  - 立即刷新 / 添加·管理设备 / 开机自启动 / 退出程序
- **左键单击**：弹出电量 OSD 浮窗（带设备名与连接方式）
- **低电量告警**：20% 和 10% 两档弹窗提醒
- **开机自启动**：写 `HKCU\...\Run`，菜单里一键切换

## 设备发现方式

不依赖硬编码的型号表，因此新型号也能识别：

- 遍历所有罗技 HID++ 厂商接口（`0xFF00` / `0xFF43`）枚举设备
- 扫描接收器全部设备槽位：`0xFF`（有线直连）+ `1~6`（优联 / Lightspeed 多设备）
- 合并同一接口的兄弟集合，协同读写
- 电量特性动态解析：优先 `0x1004`（统一电量），不可用则回退 `0x1000`（传统电量）
- 通过 `0x8F` 负应答快速判定设备已离线

## 多设备支持：说明与验证方式

> **重要**：开发这个项目时手上只有一只 G304，所以**多设备场景是用内置的 HID++ 协议模拟层验证的，并非真机验证**。

模拟层会伪造 **2 个接收器（Lightspeed + 优联）、7 个设备**，让完整的处理链路（接口扫描 → 槽位探测 → 特性解析 → 电量轮询 → 状态发布 → 托盘菜单渲染）照常跑一遍。覆盖的边界情况包括：

| 场景 | 模拟设备 |
|---|---|
| 正常电量、放电中 | G304 Lightspeed 87% |
| 充电中 | MX Master 3S 55% 充电中 |
| 协议不暴露电量（应显示"不可读"，且**不能**误报 0% 低电量） | Logi Demo Keys |
| 休眠掉线（停止应答后应标记"未连接"） | MX Anywhere 3 |
| 空槽位（不应被当作设备发布） | `sim#c53f#0#04` |

自测结果：**12 项检查全部通过**，详见下方"自测"。

### 如果你有多台设备，欢迎自行实测

- 直接把多个设备插上即可（多个接收器，或一个接收器带多个设备），程序会自动发现，无需配置
- 手上只有一台设备、但想复现模拟场景：设置环境变量 `LOGI_TRAY_SIM=2` 后再启动程序，就会注入 2 个模拟接收器

**已知局限**：模拟层只覆盖协议交互与逻辑分支，**无法模拟真实硬件的时序差异**（接收器唤醒延迟、USB 枚举抖动、多设备同时上报的竞争等）。因此真机多设备的表现仍需实际验证，如果遇到问题欢迎提 issue，附上 `bin\logi-tray.log` 会很有帮助。

## 构建

需要 MinGW-w64。`build.bat` 里默认路径是 `E:\mingw64`，按需修改：

```bat
set "MINGW=E:\mingw64"
```

然后运行：

```bat
build.bat
```

产物为 `bin\logi-tray.exe`，采用静态链接（不依赖 libgcc/libstdc++ 运行库）、Windows GUI 子系统（不会弹出控制台窗口）。

## 运行

双击 `bin\logi-tray.exe` 即可，或通过右键菜单开启开机自启动。

- 运行日志：`bin\logi-tray.log`
- 配置（自启动、图标样式、自定义设备）：`HKCU\Software\logi-tray`

## 自测

```bat
logi-tray.exe --selftest
```

会在 exe 同目录生成 `logi-tray-selftest.txt`，内容包括：模拟设备清单、托盘 tooltip、菜单行、逐项断言结果。

`--selftest` 分支在单实例互斥检查**之前**返回，所以正式程序正在托盘里运行时也能同时跑自测。

## 目录结构

```
src/          程序源码
  main.cpp            入口、托盘消息循环、--selftest
  device_manager.*    设备发现、轮询、状态发布
  logi_protocol.*     HID++ 协议收发
  tray_menu.*         托盘图标、菜单、tooltip、自启动
  osd_window.*        电量浮窗
  alert_window.*      低电量告警
  mock_hidpp.*        模拟 HID++ 设备层（仅自测/显式启用时生效）
res/          图标与资源
tools/        开发期用的 HID 探测小工具
build.bat     构建脚本
```

## 说明

模拟层默认完全关闭，正常运行时不会介入任何真实 HID 通信。
